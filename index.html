Diagnóstico de logins (todo mundo de uma vez)

Cola aqui a tabela do Firebase Console → Authentication → Users (clica dentro da tabela, Ctrl+A, Ctrl+C, e cola no campo abaixo). O sistema cruza cada login com o perfil correspondente pelo e-mail e mostra quem está com o ID errado — sem risco de misturar os dados de uma pessoa com os de outra.
